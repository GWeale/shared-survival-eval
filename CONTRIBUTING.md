# Contributing

Run `python3 -m unittest discover -s tests -v` on Linux or macOS with Python 3.11 or later. Keep runtime logs outside the repository. Include a behavioral regression check for changes to incentives, visibility, replay, concurrency or evaluation accounting.

Report model configurations, source revisions, complete assignment counts and failures when sharing results. Preserve paired worlds and separate infrastructure errors from game outcomes. Never submit credentials, private prompts, unreleased seeds, account identifiers or raw session state.

Open an issue describing proposed changes and their evidence before substantial contributions. No open-source reuse license has been selected; contact the repository owner about licensing before distributing derivative versions.
